# iPhone 免安装使用 · Lite 网页预览

日期：2026-10-29。入口：https://hindingonhome.github.io/-/

2026-10-30 修订：按 iPhone 17 Pro 的402×874逻辑像素、3倍像素比检查顶栏和横竖屏。版本标记缩小，手机“新建工作区”缩短为“新建”，页面顶部采用不透明白底和高清图标。Safari 自身的滚动边缘效果不能由网页完全控制，仍需真机复查。图文步骤见 [三版本手册](USER-GUIDE.md)。

用 iPhone 的 Safari 打开网址即可，不需要安装 App、不需要 Apple 开发者账号。此入口是手机网页预览，与已发布的 Windows/Linux 安装包独立更新。首次打开需要联网。

## 操作

1. 在“模型”页点击导入，从系统“文件”选择 STL、OBJ、PLY、GLB、GLTF；GLTF 的配套 BIN 一并选择。也可以先载入戒指或 1 mm 方块示例。
2. 确认真实模型单位。单指在画布上拖动旋转，双指缩放和平移；在画布外滑动滚动页面。
3. 底部“估算”查看体积、净重，选择金属、核对密度和手动采购单价。模型体积保持锁定；蓝白锁图标与界面一致。仅知道体积时，从“更多 → 输入体积”进入，再解锁输入。
4. 底部“记录”查看当前模型方案，支持重命名、复制、排序及打样单。点击重命名会切到估算页并定位名称输入框。
5. “更多 → 保存文件”准备 .mlab 后，点击“分享 / 存储到文件”（设备支持时）或“下载文件”。系统分享菜单中选择“存储到文件”，保存到本机或 iCloud Drive。
6. “更多 → 打开文件”从“文件”选择已保存的 .mlab。浏览器与桌面应用的缓存不互通，通过 .mlab 交换数据。

可选：Safari 分享菜单 → 添加到主屏幕。添加的是网页入口，无需下载安装包；不添加也可正常使用。

## 手机界面与资源策略

- 模型、估算、记录三栏切换；320/375/390/430 像素竖屏及 844 像素横屏进行布局检查。
- 刘海和底部安全区域留白、44 像素主要触控目标、16 像素以上输入字号、菜单和弹窗按可见高度滚动。
- 预览像素比最多1.5、画布约90万像素上限、手机渲染约30帧；后台暂停渲染。
- 手机预览最多25万面，较大网格使用轻量抽样预览；完整原网格仍用于导入时的体积计算。简化显示不等于修复模型。
- STL/OBJ 输入上限128 MiB；其他模型及 .mlab 工程上限32 MiB，工作区预览预算128 MiB。工程保存与打开使用同一32 MiB上限，超限操作会提示并保留当前工作区；请及时保存小工程，必要时减少模型或转到电脑处理。
- 网页仅提供手动采购报价，不在后台轮询隐藏的金属行情；币种换算使用标明日期的快照或已有缓存。

模型、工程和报价在浏览器本机处理，不上传到 GitHub。网址托管和初次页面资源下载由 GitHub Pages 提供。

## 缓存与测试边界

可选离线页面缓存仅用于已加载的页面资源，不缓存原始模型文件。系统可能清理网页存储，不可把缓存当作唯一工程备份。

Windows 上 WebKit 和 Edge 手机环境已检查计算、三栏、重命名、保存/恢复、三语导航及布局。Edge 离线重载检查通过；Windows WebKit 的离线重载遇到浏览器内部错误，未作为通过项。尚无真实 iPhone Safari、系统文件分享面板及旧 iOS 的实机验证。请优先使用更新的 Safari，先用示例模型试算后再处理重要工程。

## 维护

运行 pnpm build:lite:web 生成 site-lite/；执行 scripts/deploy-lite-web.ps1 将静态资源发布到独立 gh-pages 分支。main 保留可修改源码，gh-pages 仅包含网页资源。不要把 site-lite、测试用户数据或生成的 .mlab 提交到 main。
