# MetalLab Lite v1.0.0 发布前验收

日期：2026-10-29。基于用户确认的 R3 版继续自检；发布前另生成 Final 本地验收页面和平台 ZIP。

## 修复

独立审查发现：记录 ✎ 按钮定位到被隐藏的名称输入框，导致重命名无法操作。修复 Lite 专属样式，恢复输入框显示；浏览器实际点击、修改及工程恢复后名称均通过检查。

## 验证范围

- 87 项 Node 测试：计算、单位、货币、文件格式、工程校验、记录、工作区管理及 Lite 生成结果。
- Edge 浏览器：真实 STL 导入及尺寸确认；1 mm 校验方块黄金净重约 0.019 g；1 cm³ 手动体积黄金净重 19.3 g。
- 戒指/方块按钮、多模型切换、当前模型的记录隔离、重命名、删除模型、确认清空及保存/恢复 .mlab 工程往返。
- 三种语言及旧日语偏好回退；浅色弹窗、说明、记录、比较、打样单选择和更多菜单；390、760、1280 像素页面无横向溢出。
- Windows 打包应用：启动版本、独立数据目录、示例计算、原生保存、清空、原生恢复工程。
- 包内 HTML 与最终构建一致；平台 ZIP 内容及 SHA256 校验。

检查脚本：scripts/check-lite-ui.cjs、scripts/check-lite-desktop.cjs。测试记录保留在本地 delivery/lite-ui-check/，不提交临时用户数据和生成的打包文件。

## 验证边界

自动检查不能证明不存在所有缺陷。Windows 安装向导未在干净虚拟机完整安装/卸载；Linux 完成交叉构建但未实机运行。Windows 7/8.1 不支持当前桌面运行时，备用 HTML 也未实机验证。当前桌面包未做商业代码签名。
