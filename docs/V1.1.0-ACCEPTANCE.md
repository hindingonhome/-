# V1.1.0 使用与验收说明

状态：标准版已验收并进入发布；Lite单独保持本地验收。

1. 先在旧版保存重要 `.mlab` 工程及原模型。用本包便携版试验，不必先覆盖安装。
2. 导入超过 12 个小模型，逐项确认尺寸单位；也可打开包内“示例工程-30模型150记录.mlab”。应能显示 30 个模型，每个模型只显示自己的 5 份记录。
3. 点击“新建分组”，输入名称。导入前设置“导入到分组”；已有模型点击 ↪ 选择目标分组。测试改名、折叠及保存重开，模型、克重和报价应保持。
4. 切换左侧模型，检查中间记录数量及内容随之切换。用 ✎ 改名、↑↓ 排序；另一模型的顺序不变。原始记录保留，副本可以删除。记录较多时只滚动列表。
5. 导出打样单，核对选择框仅列当前模型的记录。保存工程并重新打开，确认分组和排序恢复。
6. Ctrl+N 或“更多 → 新建工作区”。先试取消，数据应保留；再试保存后新建，取消保存对话框不得清空。直接新建只清空本地工作区，不删除磁盘文件。首次保存应重新选择路径。
7. 新建后导入一个新模型，确认不会混入旧记录；关闭重开应恢复新工作区。
8. 切换五种语言，检查分组、记录操作及新建对话框。检查小窗口和缩放下的布局、独立滚动条。

“整理”操作说明：分组为单层；删除非空分组会提示先移出模型。记录通过名称和排序整理，不会把不同模型的记录混在一起。未提供跨模型移动计算方案，以免尺寸与体积基准错配。

资源边界：取消的是数量限制，不是内存限制。工作区预览预算 512 MiB，工程文件上限 512 MiB；3 百万面级模型可能占用数百 MB，请按项目分开保存。旧版不理解新增分组；务必保留原始工程。

包内备用 HTML：无需安装，可离线打开；浏览器数据和桌面版独立。浏览器 Ctrl+N 可能由浏览器处理，请使用菜单。浏览器保存采用下载，确认下载落盘后再点击直接新建。

Linux 包若存在为交叉打包产物；在 Windows 上无法实际验证 Linux 桌面启动，需在 Linux 检验运行及显示。
