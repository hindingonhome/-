# MetalLab Standard V1.2.0 · 小体积 Windows 发行版

本次优化桌面运行架构和交付方式，保留完整标准版页面及计算核心。原约167 MiB平台包同时包含两个Electron程序；新包仅放一份WebView2应用，复用系统浏览器运行环境。体积约1.2 MB，准确大小及SHA256以附件为准。

## 变更

- 新增Windows x64 WebView2宿主，使用独立用户数据目录和单实例保护；正常启动关闭调试端口。
- 不再捆绑Electron/Chromium，不在同一ZIP重复放安装版与便携版。
- 保留分组、尺寸方案、密度/单价、制作费用、STL/OBJ/PLY导出、PDF/JPG打样单、.mlab工程、五语及教程。
- 顶栏、关于窗口、EXE文件属性及发布标签统一为1.2.0。
- 附使用说明、变更日志、WebView2 SDK许可、NOTICE及第三方许可证；源码增加可复现构建、校验和手动发布流程。

## 检查

91项逻辑测试；真实WebView2程序检查方块克重、分组、200%尺寸、制作费、STL单位导出、PDF打样单、保存/清空/恢复及五语教程。旧发布包保持不变，方便回退。

## 使用要求与已知差异

Windows10/11 x64、建议.NET Framework4.8及以上、Microsoft Edge WebView2 Evergreen Runtime。解压完整ZIP运行MetalLab-Standard-Slim.exe。缺少运行环境会提示前往微软下载，环境本身仍占磁盘空间；不支持Win7/8.1。未做商业代码签名。

此发行版暂未替代Electron最近工程列表、双击.mlab关联、关联路径直接覆盖及超大导出直接写盘。通过“更多→打开文件”恢复工程，保存由对话框选路径；预览/缓冲导出采用网页资源策略。数GB文件和长期使用未做完整覆盖。需要这些原生能力时，保留使用[V1.1.0 Electron版](https://github.com/hindingonhome/-/releases/tag/V1.1.0)。

本轮不提供新Linux二进制；Linux继续使用V1.1.0。不能将Windows共享运行时方案的体积优势直接套用到Linux。
