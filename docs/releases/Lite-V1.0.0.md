# MetalLab Lite v1.0.0

以导入模型、查看体积、选择金属和计算克重为主的轻量界面。固定浅色，支持简体中文、繁体中文、English，使用独立蓝白 Lite 图标。

## 使用与下载

- Windows x64 ZIP：安装版、便携版、备用 HTML、使用说明、更新日志和许可。
- Linux x64 ZIP：便携 tar.xz、备用 HTML、使用说明、更新日志和许可。
- SHA256SUMS.txt：两份平台 ZIP 的校验值。请先解压 ZIP，避免直接在压缩包中运行。

桌面应用标识和数据目录与标准版独立，可同时保留。语言、单位、币种、工程保存和快捷键按 Lite 使用说明操作。

## 本版功能

- 载入戒指、1 mm 方块示例，或导入 STL/OBJ/PLY/GLB/GLTF；每次导入确认单位。
- 多模型下拉切换、体积与克重、密度及手动单价、当前模型的计算记录整理和打样单。
- 保存/恢复 .mlab、新建空白工作区、三语和显示单位/币种切换。
- 去掉深色模式、模型分组、高级选项入口；保留共用核心及可恢复配置。完整分组、尺寸编辑、几何导出和制作费用使用标准版。
- 发布前修复记录重命名入口被隐藏的问题，并补充保存恢复、清空、删除等操作回归。

完成 87 项逻辑测试及浏览器操作检查，并验证 Windows 打包应用的启动、保存、清空与恢复。

## 系统与计算边界

Windows 安装/便携程序面向 Windows 10/11 x64，不支持 Windows 7/8.1。备用 HTML 需要现代浏览器及 WebGL2，旧系统兼容性未实机验证。Linux 已交叉构建，未实机运行。安装程序未配置商业代码签名。

Lite 提供手动采购单价，不展示完整自动行情面板；密度、历史价格和币种汇率均需自行核对。体积与克重依赖网格正确性，不能代替模型修复或实际投料确认。
