# 金属工坊 V1.0.0

首个公开检验版。

- 离线查看 STL、OBJ、PLY、GLB、GLTF 模型，估算体积、金属理论净重与材料成本。
- 支持工艺模板、独立手动费用、单件和整批估算，以及打样单导出。
- 支持 `.mlab` 工程保存和多计算方案管理。
- 提供简体中文、繁体中文、英语、日语、韩语界面及多币种离线换算。
- 模型导入和导出都要求确认尺寸单位；显示单位切换不会改变模型实际大小。
- 提供 Windows 免安装便携版、安装版和单文件离线 HTML。

正式生产前请人工确认模型拓扑、合金密度、材料价格、损耗和工艺报价。本版 Windows 程序未使用商业代码签名证书。
