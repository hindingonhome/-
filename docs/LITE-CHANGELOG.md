# Lite 开发日志

## V1.1.0 · 2026-10-30

- 使用系统WebView2，取消ZIP内重复的Electron运行时；应用下载包约1.2 MB，共享运行环境另计。
- 统一页面/文件版本为1.1.0，保留蓝白图标、三语、手机界面及完整基础计算。
- 原生保存对话框、独立数据目录、单实例保护；增加构建和实际运行回归脚本。
- 最近工程等Electron专用集成仍有差异，见LITE-SLIM.md；历史版本和Linux旧包保留。


## 网页与 UI 预览修订 · 2026-10-29

- 增加无需安装的 Safari 网页入口和手机三栏、触控、安全区、输入字号、横竖屏及预览资源策略。
- 增加手机文件分享/下载面板和同一上限的工程保存/恢复保护；显示抽样不修改完整体积结果。
- 锁定/解锁使用蓝白线条图标，统一弹窗关闭、忙碌面板、滚动条与金属选择文字的浅色样式。
- 新增 WebKit/Edge 手机检查和独立静态网页部署脚本。此次网页预览不替换已发布 Windows/Linux 附件。

## v1.0.0 验收修订 · 2026-10-29

- 发布前审查修复计算记录重命名无响应：显示原有记录名称输入框，保留标准版逻辑。
- 增补真实保存/打开工程往返、确认清空工作区、模型删除、记录隔离和重命名检查。
- Windows 安装版/便携版、Linux x64 便携包使用独立应用标识、蓝色图标与数据目录，不覆盖标准版。

- 在计算记录上方增加标准版戒指与 1 mm 校验方块的载入按钮；复用原示例模型、计算及三语文案，不自动填入示例记录。

- 统一白色弹窗、说明、计算记录、比较表格、打样单选择、单位确认及报价提示，修复深色和棕色样式残留。
- 方向选择下拉框和画布内方向轴底色同步调整，保留模型材料色及坐标轴辨识色。
- 替换为蓝白 M / LITE 图标，准备 SVG、PNG、ICO 三种格式；保留标准版原图标。
- 语言缩减为简体中文、繁体中文和 English；旧版日语或韩语偏好回退简体中文。
- 去掉深色模式入口。模型与分组、高级选项通过 Lite 配置关闭，核心代码保留以便后续恢复。
- 新增紧凑模型下拉框和删除入口；菜单保留手动体积输入，密度与单价输入保留。
- 使用说明按当前 Lite 功能和三种语言重写；弹窗打开后收起更多菜单。
- 检查真实 STL 导入和单位确认、1 cm³ 金的净重、模型切换、工程保存、三语切换及 390/760/1280 像素布局。
- 桌面程序不支持 Windows 7/8.1；备用 HTML 亦未完成旧系统实机兼容验证。Linux 为交叉构建，尚未完成 Linux 实机运行验证。
