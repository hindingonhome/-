1. 启动、环境与旧工程

  1. 完整解压 Windows ZIP，运行 MetalLab-Standard-Slim.exe 或 MetalLab-Lite-Slim.exe。DLL、图标、web目录须保留。
  2. 需要 Windows10/11 x64、建议.NET Framework4.8及以上，以及 Microsoft Edge WebView2 Evergreen Runtime。若缺少WebView2，程序会提示前往微软官方下载，不会静默安装。
  3. 新旧应用的数据目录独立。先在旧程序保存.mlab，再在新程序的“更多 → 打开文件”恢复。首次启动没有旧记录属于正常现象。
  4. 缺少旧Electron的最近工程、双击文件关联和超大导出直接写盘等集成时，可继续保留旧版。共享运行环境和缓存仍占磁盘空间，不计入应用下载ZIP。

2. 从模型计算金属重量

  1. 初次体验可载入内置戒指或1mm方块；正式计算点击“导入模型”。支持STL、OBJ、PLY、GLB、GLTF。GLTF若引用BIN，请一起选择；STEP、3DM、BLEND和压缩网格不属于直接支持范围。
  2. 导入后先确认源坐标单位，与建模软件保持一致。不要仅凭看起来很大或很小选择单位。取消确认不会添加模型。
  3. 选择金属并核对材料密度。体积以cm³显示，理论净重单位g。净重=体积×密度；合金密度应按实际牌号调整。
  4. 检查网格提示。边界、退化、方向和拓扑警告需要人工处理；程序不会自动修复模型，自相交、壳体重叠也不保证完整识别。空心物件必须有正确内壁。
  5. 材料成本输入每克采购单价，单位按当前货币显示。价格和成品净重、投料余量分别核对，不要把损耗重复计算。

大模型可能采用抽样预览，完整网格仍参与导入时体积计算。预览稀疏不表示体积只算了一部分；但模型几何本身仍需检查。

3. 标准版：分组、尺寸方案和制作费用

  1. 模型库可新建分组；拖动模型到分组标题可移动归属。选中分组后F2或双击名称重命名。删除分组前先移出模型。
  2. 计算记录只显示当前模型的方案，切换模型时随之更改。原始记录保留；新建或复制副本后，在尺寸与比例中输入尺寸或百分比。保持比例选项决定是否联动三轴。
  3. 记录可重命名、上下排序、复制和删除副本；并排比较仅比较当前模型方案。
  4. 填写投料余量百分比，选择按成品净重或预估投料量计材料费。采购报价与自动参考价不是同一概念。
  5. 制作与附加费用可选工艺模板或手动添加。模板会替换当前费用项目，请核对后填写实际单价。费用可按克、件、数量或材料费比例计入；空白单价不会自动成为真实报价。
  6. 费用汇总填写制作数量，核对单件和整批估算。正式报价前确认供应商、日期、有效期、返料及损耗规则。

标准版提供简体、繁体、英语、日语、韩语。自动参考行情覆盖部分金属；铜及合金不能据界面预设值当作实时报价。

4. Lite：基础计算与 iPhone

  1. Lite保留体积、克重、密度、手动单价和记录整理。模型下拉框切换模型，旁边×删除当前模型及关联记录；先核对确认窗口。
  2. 已知体积时选择“更多 → 输入体积”，点击蓝白锁按钮解锁并填写cm³。几何模型体积保持自动计算，不能用手动数值覆盖。
  3. 模型分组、尺寸编辑、几何导出、制作费用使用标准版。工程中的相关数据不会主动删除，仍可在标准版继续处理。
  4. iPhone用Safari打开 手机版网址 即可，不需要安装程序。底部“模型 / 估算 / 记录”切换页面；单指旋转、双指缩放和平移，在画布外滑动滚动页面。
  5. 手机版从系统“文件”选择模型。保存工程时选择分享/存储到文件或下载，保存到本机或iCloud Drive。可选从Safari分享菜单添加到主屏幕。

Lite提供简体、繁体、英语。手机STL/OBJ输入上限128MiB，其他模型和工程上限32MiB，工程保存/打开使用同一限制。浏览器缓存可能被系统清理，请定期导出工程。旧iOS和系统分享/离线行为仍需实机验证。

5. 保存、导出、单位与货币

  1. “更多 → 保存文件”保存.mlab工程；“另存为”保留新副本。选择目标路径并确认磁盘文件已存在后再清空工作区。新建不会删除原始磁盘模型。
  2. 打开工程会替换当前工作区，请先保存需要保留的数据。跨电脑迁移时携带.mlab和重要原模型；高面数工程通常只保留预览与计算结果，再导出几何时可能需要重选原文件。
  3. 计算记录中“导出打样单”选择记录和PDF/JPG。PDF可合为多页；多张JPG放入ZIP。图纸中的待确认字段仍需人工核对。
  4. 标准版导出STL/OBJ/PLY时确认输出单位，并在接收软件选择相同单位。原始源文件不会被修改。
  5. “更多”中的尺寸显示单位仅换算显示和输入，不改变模型物理大小。切换货币按标明日期的汇率换算，内部价格以人民币保存；不是实时交易汇率。

请勿把当前WebView2版视作已完全替代旧Electron所有原生文件能力。数GB工程、旧系统和长期运行尚未做完整覆盖；重要文件保留独立备份。

6. 常用快捷键

  • 中键拖动旋转；滚轮缩放；Shift+中键平移；Ctrl+中键缩放；旋转中Alt贴合轴向。
  • F适配视图；Ctrl+S保存；Ctrl+Shift+S另存为；Ctrl+O打开；Ctrl+N新建空白工作区。
  • 标准版F2重命名已选分组。浏览器可能占用快捷键，必要时用按钮。
