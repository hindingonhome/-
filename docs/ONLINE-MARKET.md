# 自动参考行情与采购报价实施说明

用户已批准免费接口方案。V1.0.0 保留版本号并替换已有发布附件。

参考行情使用 Gold API 的 XAU、XAG、XPT、XPD（美元/金衡盎司），按 31.1034768 克/金衡盎司与 Frankfurter 的 ECB 每日 USD 汇率换算为人民币/克。铜、铝、锡和合金不自动更新。请求只包含金属代码及币种，不上传模型或报价。

启动、重新联网及每五分钟尝试刷新；隐藏页面暂停轮询。手动刷新至少间隔三十秒。每个请求有超时，响应进行金属、币种、价格、时间及完整汇率校验。单个金属失败保留其缓存，显示失败及原行情时间；超过二十四小时的行情不能一键采用，汇率超过十天不用于新的参考价换算。时间落在未来超过五分钟的数据拒绝。

参考行情保存在单独的本机缓存中，刷新不改变任何工程中的人民币单价、采购报价或费用。只有用户点击采用按钮才改变当前计算记录，同时保存金属行情时间、原始美元单价、来源及汇率日期。切换金属仍沿用已有的历史默认价格规则；自动行情独立显示，不冒充采购价。

汇率更新只影响外币显示；正在编辑输入或导出时延后应用新汇率，避免自动刷新改变正在填写的值。汇率日期和来源在菜单及导出材料中显示。网络失败使用缓存或内置快照并标明状态。

实施顺序：1. 先编写转换、错误响应、部分失败、缓存及报价保留测试，确认失败。2. 实现独立市场模块及可更新的汇率上下文。3. 接入参考行情区、刷新/采用/采购按钮、五语翻译及严格网络域名白名单。4. 更新说明书、源码 Word、登记表及源码清单。5. 运行完整测试、实际联网与桌面界面验证，再推送并重建 Windows/Linux/HTML 附件，下载核验 SHA256 和打包内容。

接口依据：https://gold-api.com/docs 、https://gold-api.com/llms.txt 、https://frankfurter.dev/ 。免费接口不保证可用性，不把每日汇率或休市行情称为实时交易价。
